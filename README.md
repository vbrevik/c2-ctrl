# MSHNCTRL C2 (Command & Control)

Decision support and battle rhythm module for staff coordination.

## Crates

| Crate | Description |
|-------|-------------|
| `decisions` | Decision tracking and routing |
| `meetings` | Meeting management and battle rhythm |
| `c2-server` | Unified server for C2 features |

## Status

⚠️ **Development**: Backend implementation in progress. Frontend components exist with mock data.

## Planned Features

- Decision routing to appropriate forums
- Meeting agenda management
- Battle rhythm integration
- Staff coordination workflows

## Quick Start

```bash
cargo build --workspace
cargo run -p c2-server
```
